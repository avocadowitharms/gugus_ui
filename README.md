# gugus_ui

A frosted-glass design system and component library for Flutter.

## Installation

Add the package from your Flutter project: ( not yet possible ) 

```shell
flutter pub add gugus_ui
```

Then import the public component library:

```dart
import 'package:gugus_ui/gugus_ui.dart';
```

To install directly from Git before the package is published:

```yaml
dependencies:
	gugus_ui:
		git:
			url: https://github.com/avocadowitharms/gugus_ui.git
```

Run the example scene directly from the root repository:

```dart
flutter run -t example/lib/main.dart -d chrome
```
